# XUYI image entries inside existing sitemap.xml (2026-10-14)

- This change extends **existing** `https://xuyibottles.com/sitemap.xml`. No new image sitemap, route, WordPress/plugin requirement or GSC dependency.
- `build.py` and `scripts/render_locales.py` create `<image:image><image:loc>https://xuyibottles.com/media/...webp</image:loc></image:image>` *during normal sitemap generation*, not by mutating completed HTML.
- `product_image_sitemap.py` selects only the one real main photo associated with a published model page. The English model image is sourced from catalog and D1 override fields in `site_renderer.SERIES`; an English D1 page-body override is also respected. For localized pages, the D1-reviewed `mainHtml` supplies that locale's selected main photo.
- Six previously approved HD shaker source-to-published mappings in `data/gpt-reviewed-shaker-hd-20261013.json` are read by the same source helper, so the Sitemap matches the final published `main-photo` URL after the legacy renderer's reviewed substitution. The original R2 files remain intact.
- Public image URLs use the site origin `https://xuyibottles.com` and existing `/media/` or `/assets/` paths; no R2 host switch, invented SKU-specific image name, resize suffix, cache-busting query or new file is introduced.
- **Stability rule:** don't rename/remove an already published photo object or rotate its public URL on routine builds, alt/title changes, or compression of unrelated media. If the owner deliberately replaces the photo in D1, the original URL is not forcibly restored; the image entry follows the newly selected asset. For permanent migrations, preserve the old URL if possible (or arrange redirects) rather than dropping indexed assets.
- Only published product pages get main photos in this iteration. This is 101 English + 404 existing reviewed translations = 505 image references on 755 unchanged page URLs. Later new verified models or published locales are auto-supported; no hard-coded route count gates.
- Existing `lastmod` values, robots/canonical/hreflang, product URLs, customer brand logos, inquiry data, and original R2 objects do not change. No deprecated `image:title`, `image:caption`, `image:geo_location`, `image:license` tags.
- `scripts/test_product_image_sitemap.py` checks every actual published product page main-photo URL against the image Sitemap, stable/repeated source resolution, image domain safety, owner-supplied D1 replacement, shared photo reuse and future SKU support.
- Google docs: https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps
