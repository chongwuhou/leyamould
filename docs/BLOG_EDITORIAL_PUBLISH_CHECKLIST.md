# XUYI 博客发布前编辑规范 / Blog editorial publishing checklist

**生效范围：从本规范建立后新写、重写或准备发布的博客文章。** 本文件是编辑流程标准，不是 SEO 算法保证，不要求通过程序批量修改旧页面。

## 发布前必须满足的两项数量要求

1. **正文中自然链接 2–5 个相关真实产品页。** 每个链接出现在与该型号有关的段落中，有清晰、自然的锚文字，并说明为什么该产品值得作为选型参照。优先不同且相关的实际型号；同一个 SKU 反复链接只算 **1 个**。不能拿首页、产品目录、分类页、导航、图片卡片或自动补链段落凑数。所有容量、材质、盖型、认证等事实仍按产品档案核对，不编造性能。
2. **正文结束处人工挑选 2–3 篇相关博客文章作为“相关阅读”（Related Reading）。** 显示明确标题和直接文章链接；推荐理由应与当前文章的采购问题互补。不得链接回自己，避免两三篇内容重复的文章互相硬凑。不把全站导航、侧栏、页脚或不经编辑挑选的通用自动推荐模块计入此要求。

## 实际审核口径

**只统计用户阅读文章时的实际正文链接 + 正文结尾人工维护的相关阅读。** 技术测试、HTML 全页链接计数、schema、站点导航以及模板推荐卡片数量都不代表编辑审稿合格。**以前对“16 篇博客已完成”的总量宣称不得替代逐篇检查**；现有 16 篇不因为制定本规范而标记为已修复。

编辑或发布人在发布之前逐项确认：

- [ ] 文中有 **2–5 个不同且真实存在的产品详情链接**，分布于内容相关的自然段落，不集中堆砌；选型说明与该具体 SKU 的已核实资料一致。
- [ ] 文章**结尾**有 **2–3 篇不同的相关阅读**，文章确实相关，标题/锚文字准确且非自链。
- [ ] 每条内部链接都已实际打开核对：目标页面可访问，型号正确，URL 不是误用的占位符；如有多语言版本，链接应使用对应语言的有效路径，且锚文字采用目标语言。
- [ ] 链接有采购用途，读者能从文章获取下一步选型或验证依据，而不是只为达到数量机械插入。
- [ ] 正文已经在 **CMS 正式文章源字段**保存并经编辑确认。后台作者后续修改的链接和正文优先，不能靠构建后替换 HTML、旧模板或自动补链覆盖人工内容。
- [ ] 编辑审查通过后再发布。未达到标准的文章保持草稿或退回编辑，不把未逐项核验的文章称为“内链整改完成”。

## 给未来内容编辑与 AI 的指令

为 XUYI 新写博客时：**写作过程中就规划并自然放入 2–5 个具体产品链接，写完正文再人工挑选 2–3 篇相关博客放到文末。** 输出正文时同时给出这些真实 URL 和锚文字以便编辑检查；如果产品/文章缺少来源证据，请先查目录与已有文章，不允许虚构 SKU、链接或材料认证。实际发布合格以编辑复核而非自动生成的链接数为准。
