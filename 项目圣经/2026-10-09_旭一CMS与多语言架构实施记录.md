# XUYI · D1 CMS、共享模板、多语言和 Clone 工具实施记录

> 不包含生产 D1/R2 备份任务：用户明确要求跳过备份。德玛隆原项目只读，所有数据库、资源和域名独立。

## 完成的代码

1. `templates/site/`：原有 shell、header、footer、sidebar 加入 home、listing、content、static、product-card、category-card 六种独立结构入口；产品和分类卡片已实际改成外部模板渲染。原有站点 136 页、85 型号、16 篇 Blog 保留。
2. 复用德玛隆 `functions/api/admin/pages.js`、`site-config.js`、`brand-config.js` 和 `functions/_shared/brand-config.js` 的验证、D1 保存和 publishRevision 协议，全部替换成旭一受控路由、品牌资料与 `XUYI_DB`。
3. 旭一 `product-content.js` 允许编辑真实 85 型号的结构化资料，草稿不影响线上；仅 `published` 内容进入静态构建，原始 Excel/JSON 不被覆盖。
4. `/api/build-snapshot` 是经校验的构建专用 D1 内容端点，GitHub Actions 的 `fetch_build_snapshot.py` 读取发布修订、页面 SEO、品牌、导航、跳转、已发布产品和已审核译文。快照不进入 `dist/`。
5. `render_locales.py` 从 D1 中完整且已审核的 `mainHtml/title/description` 生成真实子目录页面，并仅对真正存在的双语版本写入 canonical、hreflang。没有译文时不创建冒充外语的页面。后台支持逐页审阅并保存；语言上线仍由原有 publishReady 设置控制。
6. 管理台 `admin-content.js` 加入品牌、导航、页面 SEO、产品商详和完整翻译审阅入口，使用原认证令牌。
7. `clone_site.py` 增加 Fresh / CloneData **本地安全生成**，均要求新域名、新 Pages/D1/R2 名称，不自动创建 Cloudflare 资源；CloneData 仅复制源仓库中可公开的目录，不声称复制远端 D1/R2 记录。

## 端到端试验

- 构建：136 个页面、85 型号、16 篇 Blog。
- 模拟发布：D1 SEO、导航（包括移动端）、产品详情、完整西班牙语首页、hreflang、修订号共六项通过；模拟快照随即清理。
- Fresh 和 CloneData 两种模式实际生成本地隔离目录，校验后删除。
- 85 条产品英文翻译原文已写入旭一 D1 待翻译源；没有审核译文时不会发布 /es/ /pt/ /ru/ /tr/。

## 重要限制

- 由于生产 D1 当前没有审核完成的西班牙语、葡萄牙语、俄语、土耳其语页面译文，四语**不是已上线完成状态**。必须通过后台实际翻译及审核，随后将对应语言设为 publishReady。
- 生产索引仍保持 noindex/nofollow，未获批准前不打开。
- Fresh/CloneData 已完成本地脚手架与隔离校验，但并不等于第二个站的云资源已开通或 D1/R2 远程数据已迁移；需要新的凭据和显式授权才能做后续部署。
- 后台发布→GitHub Actions 的实际发布周期（30 分钟轮询）要再用生产修订触发核验，避免把模拟数据构建当成完整生产验收。
- Cloudflare 正式域名仍可能缓存历史已删除源码路径的旧 200 响应，需持续排查域名缓存规则；干净部署不包含源码。

## 典型操作

```powershell
python scripts/build_release.py
python scripts/test_release.py
python scripts/clone_site.py --mode Fresh --config deployment/clone-example.json --destination ..\new-brand --dry-run
python scripts/clone_site.py --mode CloneData --config deployment/clone-example.json --destination ..\new-brand-data --dry-run
```

若需使用本地账号权限发布，请只运行既有 `scripts/deploy-production.ps1`；Github Actions 正式工作流由本项目独立运行。绝不把德玛隆的 Token、账户、业务素材或滤芯型号清单混入旭一。
