## 本次确实修复并加入发布门禁

1. **鉴权：** 原先 `authorizedBuildRequest` 对 Cloudflare 项目令牌没有显式阻止 POST，且所有后台 GET 都可能共用校验。现在统一限制为指定 CI 读取白名单（build-snapshot/publish-state + 六个 CMS 只读接口）和 GET/HEAD；所有 POST/DELETE 及客户询盘、SMTP、Blog 等敏感读取必须用旭一管理员会话/恢复凭据。沿用原认证，无新系统。添加 `scripts/test_admin_auth.mjs`。
2. **SEO 型号页：** 85 型号中，只有容量/名称的 Title 存在重复组。将实际源型号拼入每个详情页 Title 与 Description，不猜测材质、证书、MOQ。给 `scripts/test_release.py` 添加产品 Title、Description 全站去重及 canonical 自引用发布门禁；D1 已审批自定义 SEO 仍优先。
3. **多语言模板：** `render_locales.py` 仅当同语言目标路由确实有审核译文时，才将站内链接改写到对应子目录；没有译文则明确回退英文路径，不产生 /es/ 假页面。把实际生成的已审核外语 URL 追加到 Sitemap；保持 noindex。添加独立临时快照/临时文件测试 `scripts/test_localized_templates.py`，不写生产 D1，也不发布占位译文。
4. **导航/模板：** 保留 XUYI 原有四图 Mega Menu + 公共 Header/Footer/Sidebar。对 D1 自定义新增的顶层站内导航地址，桌面和手机端同时呈现，避免新增菜单记录后没有入口。新增 `scripts/test_shared_templates.py` 覆盖 10 模板文件和电脑/手机菜单。
5. **内容数据来源透明：** `build-meta.json.contentSources` 逐一报告品牌、导航、页面 SEO、产品、页面正文、翻译分别走 D1 还是当前源码 fallback，防止把“接口存在”误认为“数据已经迁移”。

全部新测试添加至现有 `.github/workflows/publish-xuyi.yml`，仍只由既有唯一 Actions → D1 快照 → Pages 管道发布。

## 仍然不等同德玛隆的项目（按优先级）

- **P0｜Cloudflare 历史源码缓存：** 正式域名裸路径三个旧 URL 仍残留 200，带无缓存查询的请求 404。既有 OAuth 凭据 Purge 返回 Cloudflare 401/10000；未解决，须具备 Zone 清缓存权限后精确清理并复验。
- **P0｜询盘真实送达：** XUYI SMTP 未启用，尚无收件服务器/密码/真实收件验证；当前服务端 fail-closed 和邮箱/WhatsApp 替代联系已部署，不能称完整询盘闭环。
- **P1｜D1 为内容真源：** 后台 API 已有，但上述表记录均为 0；需以现有公开的已核实菜单/页面元数据做**先比对后导入**，记录审稿来源，不能把 151 条未审原始资料自动设为 published。
- **P1｜独立模板深度：** 模板目录有 10 个文件，但 `home/listing/content/static` 目前主要是 `{{CONTENT}}` 承接 Python 生成的正文，独立结构模板深度仍不如德玛隆 V1.4。不能仅按文件数量声称全部完成。应逐步把栏目结构、内容区域与业务数据拆分，保持当前 Kreat 风格及 136 个 URL 不变。
- **P1｜导航深度：** 顶层自定义链接现在能出现在桌面/手机；四栏 Products 子菜单的默认分组仍来自代码，不是任意 D1 树的全量动态渲染；如要管理全树排序/启停/删除，还需迭代并通过视觉回归。
- **P1｜完整发布：** push → D1 快照 → build → deploy 已有成功记录；后台保存发布修订之后被 30 分钟计划任务自动识别这一支仍需单独实测。
- **P1｜跨语言 UI/SEO：** 译文为 0；不能仅因为代码可生成外语页面就宣称四语上线。下一步需要真实完整译文、移动导航、CTA、表单、FAQ、hreflang 的逐页审核；不可伪造。
- **P2｜企业资料及产品实证：** 2506 容量疑点、重复模型及导入分类仍需按源图册、真实样品、检验记录人工复核；集团参考图和客户 Logo 不得虚构为旭一独立生产证据。
- **暂缓且不冒充完成：** 德玛隆的 R2 型号溢出不适用于当前小体量水杯站；完整 D1/R2 灾备按既有用户选择暂跳过；Fresh/CloneData 只有隔离脚手架，本次不新建第二个站。
