# 2026-10-10｜旭一五语导航、动态界面翻译质量及第二 R2 生产绑定验收

## 直接触发的问题
用户截图显示俄语首页产品 Mega Menu 主标题中文（俄文）正常、但菜单列及产品链接大量英文，四种非英语站均存在同源问题。之前的 `data/ui-translations.json` 仅覆盖主导航部分词条，构建器只对完全匹配的词条替换，故 135 条路线×4 语言均显示英文二级菜单。

## 改动
1. `data/ui-translations.json` 增补西、葡、俄、土四种语言通用栏目标题、产品类别、二级导航、按钮、页脚说明、可访问性描述/Alt/搜索占位符。仅保留品牌 XUYI、语言本名、企业地址/邮箱、OEM 等官方缩写。
2. `scripts/render_locales.py` 在共享页头页脚同时本地化安全属性 `alt`、`aria-label`、`placeholder`、`title`，保留所有 `href`/`src` 路径、DOM ID 和交互事件。译文正文仍源自已审核的生产 D1。
3. 新增 `data/runtime-ui-translations.json`。构建时注入纯 JSON 到翻译页面，`assets/site.js` 读取它，本地化首页轮播的三张标题、说明和按钮，以及菜单 ARIA 状态、产品页统计及询盘状态；`assets/resource-pages.js` 复用翻译字典本地化 FAQ 搜索状态。解决页面首屏是俄语、轮播自动切换后重回英文的问题。
4. 原生产 D1 中另外发现葡语 3 个产品页 SEO 标题仍为英文，7 个水壶型号详情页的图片 Alt 仍有完整英文，已按型号在 D1 翻译真源中做定点纠正，无改变容量型号、图片或 URL。D1 发布修订号应以完成远端写入后的实时读数为准。
5. 新增 `scripts/test_shared_chrome_i18n.py` 对所有 540 条多语言页面做导航/属性/可访问性与 runtime bundle 交叉比对；纳入 GitHub Actions，防止未来二级菜单漏翻译。
