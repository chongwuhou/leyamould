# 2026-10-10｜五语主导航桌面间距与响应式核查

## 用户反馈

桌面 1635px 截图显示 XUYI logo 与 Home 首项相隔过远，右端 FAQ、Contact Us、语言选择、搜索及 Instant Quote 较拥挤。用户希望让导航向 logo 移动或调整 logo 宽度，同时保持简单高效。

## 修复选择

仅调整旭一 `assets/site.css`，不放大 logo、不改内容菜单及页面 URL。

- 根因：共享头部 `.nav{margin-left:auto}` 与 `.header__inner{justify-content:space-between}` 使额外水平空间过多留给 logo 与第一项导航的间隙。
- `min-width:1051px`：头部布局从 `justify-content:space-between` 改为 `justify-content:flex-start`，并让 `.header__inner>.nav` 拥有有限、响应式的左侧边距与 `margin-right:auto`，多余宽度转移到导航和右侧操作区之间。
- 大于 1450px 时，保持原字号、logo、菜单链接与按钮大小。用户 1635px 的 HTML 浏览器实测：**logo↔导航距离从约 219px 降为 70px，约向左移动 149px**，右侧按钮没有迁移。
- `1241–1450px`、`1051–1240px`、`1051–1150px`：以较小的菜单项间距、按钮内边距和已有响应式字号确保 ES/PT 较长文案不溢出。1050px 及以下不修改既有手机菜单。
- 不改变 `templates/site/header.html` 的 DOM，也不重复制造第二套语言导航。只维护 CSS 一处，适配所有源语页面。

## 验证

使用本机独立无头 Chrome + 本地临时 HTTP Server 打开发布目录中的 `/\`、`/es/`、`/pt/`、`/ru/`、`/tr/`，检查 1635、1450、1241、1240、1150、1100、1051、1050 八种视口宽度，**40 项实机断言全部通过**：Logo 与菜单无重叠、菜单项之间无重叠、菜单与语言/询价按钮无重叠、页面没有横向滚动；1050px 及以下导航按预期收起。

原始首次验证发现 ES/PT 在 1241 与 1051px 有横向溢出，已在第二轮针对响应式阈值修复后重新实机验收。发布门禁继续执行 `test_release`、`test_localized_release` 和 `test_shared_chrome_i18n`。不修改生产 D1 内容，不碰无关项目。
