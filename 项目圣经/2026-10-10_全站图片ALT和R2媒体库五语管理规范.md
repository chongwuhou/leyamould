# XUYI 旭一｜全站图片 ALT 与 R2 五语素材描述｜2026-10-10

## 真实审计结果

- 公开发布 675 个内容页（以及站内 404/后台文件），静态构建含 **10,811 个 `<img>` 标签**。开始审计时全都有 ALT 属性且为非空。这不代表内容质量已经完全达到最佳状态。
- 大量重复 ALT 来自**在每个页面都出现的导航菜单图片**；同一资源重复使用描述不是「675 个独立产品图片没做 SEO」，不需要给同一图片胡乱制造不同关键词。
- 已确实查出并修复不自然的标签：来源 Excel 商品中的「透明款」中文后缀、型号 2506 被连续写两次、「view 1 / visualizar 1 / вид 1 / görünüm 1」等图库占位后缀。
- 核心商品配图优先使用 **可核实的容量 + 产品分类 + 型号**。例如英文 `550ml Plastic Sports Water Bottle model 2501`、中文解释为「550ml 塑料运动水杯 2501 型号产品图」；外语图片描述应在对应语种准确表达。没有证据不应写「BPA-free / 100% leakproof / FDA certified / dishwasher safe」等属性。
- ALT 是实际照片内容的简明替代说明，不是把 `wholesale plastic bottles, supplier, manufacturer, OEM, private label, custom logo` 全部塞入每张图。只有图片实际展示批量包装、工厂工序、Logo 印刷等场景时才加入相关长尾词。
- Google 官方图片 SEO 指南：https://developers.google.com/search/docs/appearance/google-images?hl=zh-cn

## 此次框架/后台升级

1. 后台 **R2 图片管理** 新增「图片 ALT（英文，必填）」；英文是源语言。西语、葡语、俄语、土耳其语的输入框动态读取 D1 语言注册表，**可以选填**，人工审核后可逐项维护。
2. 现有 R2 媒体卡片新增「编辑图片 ALT · SEO / GEO」；除了后来上传的 product/page/shared 图片，也支持在不修改或删除原图的情况下，为受保护的 PPT、Excel、Blog、工厂、产品图库添加描述。原图库仍严格禁止直接删除。
3. 管理后台先检查文件实际存在，然后将每张图的语言描述单独保存到 D1 表 `xuyi_media_alt`（`path` 为主键、`alt_json` 为五语映射、更新时间）；触发 `publishRevision` 由既有 GitHub Actions 自动重建。不采用修改 R2 URL 或图片原始内容的方式存 ALT。
4. 旧有 `/api/build-snapshot` 增加 `mediaAlts`，仅授权的构建可读取，经 `media_alt_render.py` 统一应用到英文/多语言 HTML 对应图片。相同图片如果某语言尚未审核 ALT，**沿用该页面已经存在的文本**，绝不能拿英文覆盖外语。动态 D1 Blog 的英文封面及文章卡片也会读取已保存的英文 ALT；未设置时保留文章标题作安全回退。
5. 首页 Banner 原有五语独立 ALT 字段保留；从 Banner 编辑器直接上传的新 R2 图片先提交其英文 ALT。之后仍需点击「保存三张 Banner」才会更换正式首页。
6. `image_alt_quality.py` 从模板生成器修正可证实的 Excel 标签和画廊占位文本；不会批量幻想图片颜色、盖型、材质、使用环境或真实工厂证据。
7. CI 新增 `scripts/test_image_alt_seo.py`，对全站 `<img>` 标签完整性和上述遗留问题强制检查，并模拟 D1 英文/西语 ALT覆盖、外语缺译回退及拒绝恶意 HTML。后台新增描述和上传动作继续由 `scripts/test_media_library.mjs` 测试。

## 管理员上传/修改操作

进入 XUYI 旭一后台 → **R2 图片管理与引用检查**。

1. 选择「产品图片 / 页面图片 / 公共素材」，选中 JPEG、PNG、WebP，填写准确的英文 ALT。可按已有语言填西、葡、俄、土语 ALT，点「上传到 R2」。
2. 上传完成复制返回的 `/media/...` 路径，到商品/正文/Banner CMS 实际引用这张图片。上传了但没有挂到页面的 R2 图片不会凭空成为搜索引擎可收录页面内容。
3. 已上传或已有的受保护图片，在媒体卡中展开「编辑图片 ALT」，可按语言修订；英文 ALT 必须一直保留。保存后等待 D1 发布修订被 GitHub Actions 构建到正式站。
4. 核查发布后实际网页 HTML：对应图片 `src` 精确匹配、`alt` 是正确语言、与图片真实内容相符。图片被页面复用且描述语境不同的场合应优先保持该页面更准确的文本，避免强制统一。
5. 禁止通过文件名自动猜测材质或证书。对原 PPT/Excel 等来源图片的新增语言 ALT 建议人工比对实际图片或可信产品源目录后再保存。

**重要：上传 ALT 是独立于商品页面修改的功能。ALT 描述存储在 D1、只在内容实际引用该图后参与网站静态构建；不会更改模型参数、已有型号、产品数据或其他站点。**

收录仍保持 `indexingApproved=false`，不可因 ALT 完整就自动开放 Google 索引。Cloudflare 旧源码缓存清理仍是独立未解决的上线阻断项。
