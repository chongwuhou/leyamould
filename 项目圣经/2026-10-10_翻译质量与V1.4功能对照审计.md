# 2026-10-10｜旭一四语翻译质量与德玛隆 V1.4 功能逐项核查

## 范围与口径

- 对比旭一独立 `dist/` 中英文 135 条业务路线 × 西、葡、俄、土四语 = 540 条外语页面；英文和本地语言正文逐文本节点比对；对照生产 D1 快照、业务 SEO、页面 HTML 标签、链接、型号及已生成 Sitemap。
- 德玛隆项目 `demalong-replacement-filters/项目圣经/BACKEND.md`、`deployment/README.md` 和两站 `functions/api/admin`、`scripts` **只读**核对，未修改德玛隆代码和数据库。
- 机器翻译的结构检查 **不等于**母语术语、法律、文化与产品真实性终审。

## 查到的翻译问题与修复

| 缺陷 | 检查结果及处理 |
|---|---|
| 葡语 2215、2250 型号的核验说明仍是整句英文 | 改成葡语，保留 2000ml、PC+PP+ABS、订单前验证等事实边界 |
| 葡、俄语部分产品颜色仍是整句英文 | 对 2315–2318、2405 的颜色描述本地化，原有图片/型号没有改变 |
| 西、俄等页上的 1,000 mL、1-color 等买家提示有英文原句 | 翻译文字，保留数字、单位含义和网页结构 |
| 土语 OEM 标签、俄语开模面包屑残留英文 | 定点修正；OEM 技术缩写仍原样保留 |
| 英、四语产品 SEO 标题和描述重复型号 | 共定位 **8 个型号**：2506、501、502、507、509、510、5247、5248。修正 D1 中 8 条英 SEO + 四语 32 条翻译记录，并修正 Python 原始生成逻辑，后续构建加入型号重复检查 |
| 四语页脚 FAQ 标签未翻译 | 在现有共享 UI 词典中增加对应的本地语种标签；不改导航链接 |
| 英语完全未变的词段 | 大部分属于企业显示名称、地名、邮箱和 `PC+PP+ABS+silicone` 材料字符串，应保留或按商业用法统一，不应盲目替换 |

修复后的 135 个页面每语种共约 9,216 个较长英文正文节点中，剩余与英文**完全一致**的较长文本数量：西 8、葡 9、俄 3、土 2，主要为以上合理保留项。这个数量不代表全部翻译绝对正确，也不是自动语言质量评分。

**已识别但没有假装等效的问题：**四个外语联系页面为了满足现有 D1 HTML 安全白名单，原英文联系表单被替换成邮箱/联系入口；联系功能与英文表单页面 **并不完全一致**。SMTP 尚未通过真实发信验收，不能为了页面一致贸然启用线上表单。

## 德玛隆功能对照

| 模块 | 旭一真实状态 | 差异 |
|---|---|---|
| Cloudflare Pages + Functions + 独立 D1/R2 + GitHub 发布 | **已实现且已生产部署** | 沿用 V1.4 无服务器架构 |
| 多类型版本化页面模板 | **有 18 个复用模板** | 文件数更多，但首页及部分业务正文仍由 Python 源码生成 |
| 导航、页面 SEO、品牌、联系人 | **D1 管理和构建集成** | 完整导航树的每一个新增/删除/排序操作尚需专项可视化 E2E |
| 产品/页面内容 CMS | **85 型号、22 页面已在 D1 发布** | 产品 API 只支持 `MANAGED_MODELS` 白名单中的现有型号，不能按德玛隆标准自由导入新型号并批量生成 |
| 多语言配置、静态页面、hreflang、Sitemap | **EN + ES/PT/RU/TR 共 677 HTML 已通过发布门禁** | 语种数不同是业务选择；外语联系表单不是完全等效 |
| 翻译管理和提供商任务 | **翻译任务 API/设置已有；四语页面译文已存 D1** | 这次 540 页属于机器辅助处理并写入审核表，不等于人工审校；页面源变更→译文失效/重排队仍应做完整 E2E |
| 媒体库与 R2 | **基本上传/浏览/图片路由可用** | 没有证明具备德玛隆的完整素材来源证据、审核状态、容量配额与所有变体处理 |
| 301/302 重定向 | **D1 `site_redirects` API + 生成 `_redirects` 已有** | **不是缺失**；后台操作和生产跳转效果仍需 E2E，不能把有接口等同已验收 |
| 询盘分配与 SMTP | **D1 表单/联系人/SMTP 安全门禁存在** | 真实邮件收件及跨语种询盘闭环未验收；SMTP 配置缺失 |
| 定时 D1 revision → GitHub 自动部署 | **CI 轮询逻辑存在、push 发布成功** | 真实 schedule 任务 37980251382 已成功检查版本并因 D1 无变化而跳过部署；尚未验证 D1 有新修订时 schedule 自动构建部署的全链路 |
| Demalong `catalog` 批量型号导入与多状态审核 | **未等效移植** | 当前旭一后台不能输入任意新杯型后一键生成所有类目/语种页面 |
| Demalong `research` 证据、Claims、媒体审批及研究质量门禁 | **未移植** | 材质/食品接触文件、规格、实验及实拍来源仍缺同等级证据链 |
| 自动 R2 大批量型号溢出 | **没有移植** | 目前静态文件数小，暂不需要，保留文件数保护即可；不是当前 P0 |
| 完整 D1/R2 便携备份恢复、Fresh/CloneData 全站复制 | **不等效** | `clone_site.py` 明确仅本地脚手架，既不建 Cloudflare 资源也不迁 D1/R2；按此前用户决定未做自动完整备份 |
| Cloudflare 历史裸路径源文件缓存 | **仍未清除** | 目标 Zone Purge 凭据曾返回 401/10000，需具备清缓存权限的账号处理 |
| SEO 开放收录 | **仍 noindex** | 机器翻译未经专业语言审核，不建议直接解除索引保护 |

## 后续优先级

1. 先将已修复的翻译和型号 SEO 版本部署到正式站，核对 D1 与生产修订号。
2. 若需要与德玛隆“全部业务框架”同等级，优先补 **新增型号/批量导入 → 资料与证据审核 → CMS/翻译同步 → 一键重建**，而不是复制滤芯行业字段。
3. 补外语表单与英文版的功能一致性，但 SMTP 未验证前保留 fail-closed。
4. 实测真实 schedule 发布、301/302、生效导航树及媒体归属审核。
5. 便携备份和 Fresh/CloneData 按用户已选的暂缓原则，不为了宣称复制完整而未经允许执行。

**总体结论：共用核心架构已经复制适配；德玛隆 V1.4 的全部业务管理闭环尚未复制完整。**
