# LEYA MOULD 复用边界与后续缺口

## 当前原则

1. 本仓库只复用水杯项目已经验证的模板、渲染器、Pages Functions、D1/CMS 后台和发布门禁。
2. 水杯项目仓库、Pages、D1、R2、域名、凭据和线上内容在本项目中全程只读；遇到不明规则，先查水杯项目的项目圣经。
3. LEYA MOULD 使用独立的 GitHub 仓库、Cloudflare Pages、D1、R2、KV、域名和 CI 凭据。
4. 水杯项目的产品、Blog、评价、询盘、图片和历史发布数据不迁移；LEYA 自己已经审核的业务数据只进入 LEYA D1/CMS 和 R2。
5. 当前 112 条型号参考记录已经进入 LEYA D1，112 个压缩后的产品媒体已进入 LEYA R2，并由 `build-meta.json` 与 `r2-usage-index.json` 验证；这不是水杯项目数据，也不代表所有产品事实都已补齐。

## 已纳入系统

- Cloudflare Pages 静态预渲染、Pages Functions、D1/CMS 内容真源与 R2 媒体管理。
- 共享页面模板、后台认证、询盘、产品/页面/SEO/翻译/Blog 管理和发布 revision。
- GitHub Actions 构建、文件数保护、链接/结构化数据/多语言/媒体引用回归检查。
- LEYA MOULD 独立部署配置和资源绑定；不复用水杯项目的运行时资源。

## 当前缺口

- 前台视觉已经按目标站冻结；后续不得以后台数据任务名义改动共享 CSS、导航、页脚或侧栏布局。
- 以 cap-molds.com 为前端参考、以 hmould.com 为资料参考的边界已经写入型号参考库流程；引用资料不等于 LEYA 自有交付事实。
- 112 条型号参考记录、R2 对象、ALT 和线上静态回退已完成基础链路；产品事实、PDF、案例和多语言仍需逐项审核。
- DNS、GitHub Actions、Pages、D1/R2 独立凭据与生产回读已接通；每次内容发布仍须重新核对 source revision、publish revision 和 R2 索引。

## 下一阶段（只在后台数据准备完成后执行）

1. 完成 112 条参考记录的 LEYA 自有资料审核，并补齐真实参数、PDF、图片来源和英语/西班牙语字段；没有资料的字段保持待确认。
2. 在 LEYA D1/CMS 建立并审核 News/Blog、YouTube 视频、评价/案例和页面 SEO；不复制水杯固定批次或评价规则。
3. 通过后台保存后先做 D1/R2 回读，再按统一双构建、媒体引用、SEO、多语和线上路由门禁发布；前台模板与 CSS 继续冻结。
4. 新增模具类别先登记 `functions/_shared/mould-routes.js`、公开路由和详情模板，再从草稿转为发布状态。

## 禁止误操作

不得修改水杯项目，不得连接水杯项目 D1/R2，不得复制水杯项目业务数据或凭据，不得把参考资料写成 LEYA 事实，也不得在 D1/R2、CI、revision 和线上回读未完成前宣称内容已上线。
