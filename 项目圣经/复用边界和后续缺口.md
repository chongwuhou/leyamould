# LEYA MOULD 复用边界与后续缺口

## 当前原则

1. 本仓库只复用水杯项目已经验证的模板、渲染器、Pages Functions、D1/CMS 后台和发布门禁。
2. 水杯项目仓库、Pages、D1、R2、域名、凭据和线上内容在本项目中全程只读；遇到不明规则，先查水杯项目的项目圣经。
3. LEYA MOULD 使用独立的 GitHub 仓库、Cloudflare Pages、D1、R2、KV、域名和 CI 凭据。
4. D1/R2 当前保持空白是设计要求，不迁移水杯项目的产品、Blog、评价、询盘、图片或历史发布数据。
5. 所有业务内容后续必须进入 LEYA MOULD 自己的 D1/CMS 和 R2，再由本仓库的共享模板与构建流程生成页面。

## 已纳入系统

- Cloudflare Pages 静态预渲染、Pages Functions、D1/CMS 内容真源与 R2 媒体管理。
- 共享页面模板、后台认证、询盘、产品/页面/SEO/翻译/Blog 管理和发布 revision。
- GitHub Actions 构建、文件数保护、链接/结构化数据/多语言/媒体引用回归检查。
- LEYA MOULD 独立部署配置和资源绑定；不复用水杯项目的运行时资源。

## 当前缺口

- 将前端从继承的水杯展示内容改造成 LEYA MOULD 的模具信息架构。
- 以 cap-molds.com 为整体前端与导航参考，以 hmould.com 为产品分类、工艺和企业内容补充参考。
- 建立真实的模具产品、图片、技术参数、案例和多语言内容后，再写入 LEYA D1/R2。
- DNS、GitHub Actions 独立凭据、Pages 首次生产部署和线上回读尚未完成。

## 禁止误操作

不得修改水杯项目，不得连接水杯项目 D1/R2，不得复制水杯项目业务数据或凭据，不得在 DNS/CI 未验证前宣称 LEYA MOULD 已上线。
