# XUYI 架构与数据真源

## 技术层

- Cloudflare Pages：部署预渲染 HTML/CSS/JS/图标，不运行常驻应用服务器。
- Pages Functions：使用现有 `functions/` 提供询盘、D1 Blog、站点设置和 Admin API。
- D1：旭一 Blog、询盘、后台安全、网站联系人及语言设置、发布修订记录的生产数据真源。
- R2：现有真实产品、图库、集团已授权图片和 Blog 上传封面；静态图片走本域 `/media/`。
- 版本化 `templates/site/`：四个共享结构模板；导航链接仍由旭一的业务数据生成。
- `scripts/build_release.py`：把 `build.py` 生成的网页和允许公开的资源组装到 `dist/`。
- `scripts/preflight.py` 与 `scripts/test_release.py`：品牌/绑定/SEO/链接/文件数/模板一致性门禁。
- `.github/workflows/publish-xuyi.yml`：对标德玛隆的定时 D1 revision 检查和 CI 构建/部署控制器，依赖本仓库专用 GitHub Actions 凭据。

## 当前真实情况（不能把目标当完成状态）

| 内容 | 当前真源 | 后续方向 |
| --- | --- | --- |
| Blog 新文章/已导入文章 | XUYI D1，公开文章通过 Pages Function 读取 | 保留动态发布/草稿机制 |
| 联系人、语言设置、翻译队列 | XUYI D1 + 公共只读设置 API | 完成多语静态页面及 hreflang |
| 产品目录/商详 | `data/products.json` 和旭一专属内容模块 | 再迁移到 D1 受控数据，不直接混用滤芯型号机制 |
| 主页、Capabilities、Why Us | XUYI 源码 + JSON 结构内容 | 逐步支持后台受控内容编辑 |
| Header、Footer、Sidebar | `templates/site/` | 永远只修改模板，不改每个生成页面 |
| 图片 | XUYI R2 及当前随仓资产 | 核对全部素材归属与来源 |

## 无回归保证

迁移基线生成时 136 个预渲染页面 SHA256 全部未变，产物与历史根目录 HTML 一致；上线后按照 D1/R2、SEO、FAQ、联系人和不同语言分层回归。

## 隔离要求

生产构建只允许 `xuyi-drinkware-site`、`xuyi-drinkware-d1`、`xuyi-drinkware-r2`。
禁止把德玛隆 `CATALOG_DB`、`MEDIA_BUCKET`、`MODEL_PAGES_BUCKET`、品牌、产品数据、密钥引入旭一。
